# Death Shockwave

When a human survivor dies, five rings spread 750u from the body and hit only the infected: 1000 to commons, specials and witches, 1500 to tanks.

**Modes:** `hd4l`, `hd4lsurvival`, `hd4lfort`, `hd4lfreebuild`

**Code:** `addon/scripts/vscripts/death_shockwave.nut`. Knobs sit at the top of each script.
