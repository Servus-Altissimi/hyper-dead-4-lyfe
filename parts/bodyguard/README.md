# Bodyguard

Bots keep up with the humans: 1.3x speed, 2x and more when they fall behind (up to 2.8x), a warp onto the human's recent path after 4 s stuck 1200u away, or right away when a horde is on a bot 700u away. Revive count held at zero, instant revives, faster bot reactions.

**Modes:** `hd4l`, `hd4lversus`, `hd4lsurvival`

**Code:** `addon/scripts/vscripts/bodyguard.nut`. Knobs sit at the top of each script.
