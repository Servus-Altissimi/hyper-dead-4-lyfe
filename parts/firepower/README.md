# Firepower

Human survivor guns: 1.2x fire rate, 1.25x reload (1.6x on adrenaline), 1.25x clip, 1.3x reserve. Mounted guns never overheat.

**Modes:** `hd4l`, `hd4lversus`, `hd4lsurvival`, `hd4lfort`, `hd4lfreebuild`

**Code:** `addon/scripts/vscripts/firepower.nut`. Knobs sit at the top of each script.
